- **Discussions:** [get-h3/h3/discussions](https://github.com/get-h3/h3/discussions)
- **Umbrella project:** [get-h3/h3](https://github.com/get-h3/h3)

## Protocol Compliance

To verify your harness against the H3 protocol, use the test battery:

```bash
pip install hermes-h3-shim
h3-test --endpoint http://localhost:9191
```
